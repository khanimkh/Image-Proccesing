
# Image Processing Project

This project provides a comprehensive set of exercises, code, and explanations for manipulating 1D and 2D signals (images) in both the spatial and spectral domains. It is designed for students and practitioners to learn and apply key image processing techniques using Python, NumPy, OpenCV, and Matplotlib.

## Project Structure

- **Analyze 1D signals/**: Jupyter notebooks and resources for 1D signal analysis and filtering.
- **Analyze 2D signals/**: Jupyter notebooks and resources for 2D image processing, including spatial and frequency domain techniques.
- **Segmentation/**: Notebooks and code for image segmentation exercises.
- **images/**: Example images used in exercises and demonstrations.


## Main Features

- Spatial filtering (convolution, median, Gaussian, Laplacian)
- Histogram equalization and contrast enhancement
- Edge detection and enhancement
- Morphological operations (e.g., coin counting)
- Fourier transform and spectral analysis
- Spectral and homomorphic filtering

## Getting Started

1. Clone the repository and install the required Python packages (NumPy, OpenCV, Matplotlib, SciPy).
2. Open the Jupyter notebooks in the `Analyze 1D signals/`, `Analyze 2D signals/`, or `Segmentation/` folders to explore the exercises and code.
3. Refer to the markdown summaries for step-by-step explanations and annotated code.

## Usage

The notebooks are organized as educational modules. Each section introduces a concept, provides code, and includes visualizations to reinforce learning. You can run and modify the code to experiment with different filters and images.
